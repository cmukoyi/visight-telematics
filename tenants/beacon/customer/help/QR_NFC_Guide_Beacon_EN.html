01 What is QR/NFC Tracking? New

QR/NFC tracking extends your Beacon Telematics platform with a lightweight, infrastructure-free way to record the location of any physical asset. There are no fixed readers, no Bluetooth gateways, and no specialist hardware required beyond a printed label or an NFC sticker.

Each asset receives a unique identifier — a Pinplot Asset ID — embedded in a QR code or programmed into an NFC chip. When a member of staff, a driver, or any authorised person scans the code with a standard smartphone, the platform records their GPS coordinates and immediately moves the asset's marker on your live map.

Key Benefit

Because the scan happens in a standard mobile browser, no app download is required. Any iOS or Android device with a camera and internet access can update an asset's location in under 10 seconds.

What you can track

The feature supports three code types to cover different operational needs:

Code TypeUse CaseOutput
Asset QRVehicles, equipment, containers — anything with a flat surface for a stickerBeacon Telematics tracking URL encoded as a QR image
NFC TagAssets where scanning is impractical — tap phone to tag insteadBeacon Telematics tracking URL written to an NFC chip

What happens when a code is scanned

  1. Camera detects the QR URL. iOS and Android cameras automatically read QR codes and show a tap-to-open banner — no app needed.
  2. Browser opens the Beacon Telematics landing page. The page at portal.beacontelematics.com/asset/HPSQ… loads and displays the asset name.
  3. Location permission is requested. The first time a user scans on a given device, the browser asks for location access. This is remembered for all future scans.
  4. GPS coordinates are captured. The browser uses the device's GPS chip (enableHighAccuracy: true) for the best available accuracy — typically 3–15 metres outdoors.
  5. Location is posted to Pinplot. The coordinates and asset ID are sent to POST /api/scan. The scan is recorded in the full history log.
  6. Map updates in real time. The asset's marker moves to the new position on every open Beacon Telematics dashboard session simultaneously.
GPS Accuracy

Scans with accuracy worse than 500 metres are automatically rejected. The scanner page shows the accuracy value so the user knows if they need to move to a better location. Accuracy is stored with every scan and shown on the map popup as a dashed radius circle.

03 Code Types

Asset QR

The primary tracking method. A unique HPSQ… identifier is embedded into a QR code that encodes the full Beacon Telematics asset URL. Print it on a label, attach it to the asset, and it is ready to scan immediately.

Best for: vehicles, trailers, site equipment, containers, pallets — any asset with a surface area large enough for a sticker (minimum ~25mm square for reliable scanning).

NFC Tag

Works identically to Asset QR but uses near-field communication instead of a camera. The same Pinplot URL is written to a blank NFC chip using any NFC writer app. When a user holds their phone within a few centimetres of the tag, the browser opens and the scan proceeds exactly as with a QR code.

Best for: assets in dark environments, assets that are handled frequently (so scanning is awkward), or high-value items where a discreet embedded chip is preferred over a visible sticker.

NFC Compatibility

Background NFC reading requires iOS 13+ (iPhone 7 or later) or Android 9+. Most devices in active use since 2020 are compatible. Android has supported NFC for longer and with fewer restrictions than iOS.

IMEI / MAC

Encodes a hardware identifier as a plain-text QR code — not a Pinplot URL. Scanning the code displays the raw value (e.g. 357012345678901) which the operator can read or copy. This does not update the Beacon Telematics map; it is purely for identification labelling.

Best for: laptops, tablets, routers, network switches — any device where you want to avoid manually reading a serial number from a sticker.

Phone Camera Behaviour — IMEI/MAC

Native iOS and Android camera apps may show a "Search" prompt rather than displaying plain text directly. For IMEI/MAC codes, instruct your team to use Google Lens or a dedicated QR scanner app, both of which display the raw decoded value.

04 The QR Generator

The Pinplot QR Generator is a browser-based tool — no installation required. Open it on any computer with a modern browser. It is organised into three columns that guide you left to right.

ColumnPurpose
① ContentChoose the code type (Asset QR, NFC Tag, or IMEI/MAC), generate or enter the identifier, and configure QR-specific settings.
② AppearanceCustomise colours, corner styles, frames, and centre icons. All settings are optional — defaults scan reliably out of the box.
③ Preview & DownloadLive preview updates as you make changes. Download when satisfied. Download history is shown below the preview for re-downloads.
Tip

The tool has a dark mode toggle in the top-right corner. Both modes produce identical output — the theme only affects the tool UI, not the downloaded QR image.

05 Creating an Asset QR
  1. Select the "Asset QR" tab in the Content column. A unique HPSQ… ID is generated automatically and displayed as portal.beacontelematics.com/asset/HPSQ….
  2. Review the generated ID. Each ID is unique. If you need a fresh one — for example because you made several attempts — click ⟳ New ID.
  3. Customise appearance (optional). Adjust colours, select a frame, or add a centre icon in the Appearance column. The preview updates live.
  4. Click "⬇ PNG" or "⬇ SVG". A confirmation dialog will appear before the download proceeds.
  5. Confirm registration. The dialog explains that downloading registers the asset ID with the platform. This is a one-time action per ID — re-downloading the same code will not create a duplicate charge.
  6. Print and attach the label to the physical asset.
Important — Register on Download

An asset is only registered in the Beacon Telematics database when you click download. IDs that are generated but never downloaded are not registered and cannot be scanned successfully. This design keeps your asset registry clean.

FormatBest for

06 Creating an NFC Tag

NFC tags are programmed, not printed. The generator produces a URL that you write to a blank NTAG213 or NTAG216 chip using an NFC writer app.

  1. Select the "NFC Tag" tab in the Content column. A unique HPSN… ID is generated and displayed.
  2. Click "🔗 Copy NFC URL" in the preview panel. A confirmation dialog appears. After confirming, the full URL is copied to your clipboard.
  3. Open your NFC writer app on your phone (e.g. NFC Tools, Trigger, or TagWriter). Create a new URI record.
  4. Paste the copied URL into the URI field and write it to the blank chip. The write takes under one second.
  5. Test the tag by holding your phone close to it. The Pinplot landing page should open automatically.
  6. Attach or embed the chip on the asset in a location that is accessible for tapping.
Recommended NFC Hardware

Standard NTAG213 stickers work for most use cases. For harsh environments (outdoor, machinery, temperature extremes), use on-metal NFC tags rated for your operating conditions. Chips with at least 144 bytes of memory will accommodate the Pinplot URL.

07 IMEI / MAC Codes

IMEI/MAC codes are plain-text QR codes — they do not link to Pinplot and do not update the map. They are identification labels only.

  1. Select the "IMEI / MAC" tab.
  2. Enter the value — either a 15-digit IMEI number or a colon-separated MAC address (e.g. AA:BB:CC:DD:EE:FF).
  3. Optionally enter a label prefix such as IMEI or MAC. This prepends the label to the encoded value (e.g. IMEI:357012345678901). Leave blank to encode the raw value only.
  4. Download PNG or SVG — no confirmation dialog is shown because IMEI/MAC codes are not registered with the platform.
Scanning IMEI/MAC Codes

On industrial scanners (Zebra, Honeywell, Datalogic) the decoded value appears directly. On phones, use Google Lens or a dedicated QR scanner app — the native camera app may display a "Search" option rather than the raw text.

08 Bulk Generation

When fitting out a fleet, stocking a warehouse, or programming a batch of NFC tags, you can generate multiple unique codes in a single operation without changing any of the appearance settings.

Bulk Asset QR (ZIP)

  1. Select the "Asset QR" tab and configure your appearance settings as normal.
  2. Set the Quantity field to any value between 2 and 250. The hint text updates to confirm the number of codes and the output format.
  3. The PNG button changes to "⭳ ZIP (PNG)". The SVG option is hidden — bulk export is PNG only.
  4. Click "⭳ ZIP (PNG)". The confirmation dialog summarises the number of codes being registered.
  5. Confirm. The generator renders each QR sequentially, showing a live progress bar. When complete, a single ZIP file downloads containing one PNG per asset ID, each file named by its ID.
Billing

Each unique ID in a bulk batch is a separate billable registration. A batch of 50 codes registers 50 assets. Re-downloading the same ZIP file will not re-register or re-charge IDs that already exist.

Bulk NFC Tags (Excel)

  1. Select the "NFC Tag" tab and set the Quantity field to the number of tags required.
  2. The "Copy NFC URL" button changes to "📊 Download Excel".
  3. Click "📊 Download Excel" and confirm the dialog. An .xlsx file downloads immediately.
  4. Open the Excel file. Each row contains: Asset ID, NFC URL, Type, and Status columns. Use this file to track which chips have been programmed.
  5. Copy each URL from the Excel into your NFC writer app to programme each chip.
09 Scanning with a Phone

Scanning an Asset QR or NFC tag with a phone requires no app installation. The process is entirely browser-based.

QR Code

  1. Open the native camera app on iPhone or Android. Point it at the QR code — the banner "portal.beacontelematics.com/asset/HPSQ…" appears automatically.
  2. Tap the banner. Safari or Chrome opens the Beacon Telematics asset landing page.
  3. Allow location access when prompted. This is a one-time permission per device — the browser remembers it for all future scans.
  4. Wait for the confirmation. The page shows "✓ Location updated successfully" once the scan is recorded. The GPS accuracy and scan number are displayed.
  5. Close the browser tab. The scan is complete.

NFC Tag

Hold the phone within 2–4 centimetres of the NFC tag. The banner or notification appears automatically — tap it and the same landing page opens. The rest of the process is identical to a QR scan.

GPS Outdoors vs Indoors

Outdoors, smartphone GPS typically achieves 3–15 metres accuracy. Indoors, accuracy degrades to 50–300 metres as the device falls back to WiFi and cell triangulation. Scans worse than 500 metres are rejected. The accuracy value is visible on the landing page and stored with every scan.

What the map shows

Every Asset QR and NFC scan moves the asset's marker on the Beacon Telematics live map. Marker colours indicate the scan source:

ColourSource
GreenQR code scan
AmberNFC tap

A dashed accuracy circle around each marker scales to the GPS accuracy value at time of scan. Clicking the marker opens a popup with the asset name, ID, type, accuracy, total scan count, and last-seen timestamp, plus a link to the full scan history.

10 Map Updates

The Pinplot map receives scan events in real time using a Server-Sent Events (SSE) stream. As soon as a scan is confirmed by the server, every open Beacon Telematics dashboard session receives the update and moves the marker — no page refresh required.

Asset QR scanned
→
GPS captured
→
POST /api/scan
→
Map marker moves

On page load, the map fetches all current asset positions from GET /api/assets and renders markers for every asset that has been scanned at least once. Assets that have been registered but never scanned do not appear until their first scan arrives.

Scan history

Every scan is stored permanently in the database. The full history for any asset is available from the map popup via the "View scan history" link. This enables movement trail visualisation and audit reporting.

11 Asset ID Format

Every Pinplot asset ID follows a fixed 15-character format that encodes the asset type and guarantees uniqueness.

HPSQ12345600102
HPS — fixed platform prefix
Q or N — code type (QR / NFC)
6 digits — last 6 digits of Unix timestamp (ms)
3 digits — rolling counter (000–999)
2 digits — random suffix (00–99)

The combination of millisecond timestamp, rolling counter, and random suffix makes ID collisions statistically negligible even when generating many IDs concurrently. The type code at character position 3 tells every part of the system whether the physical medium is a QR sticker or an NFC tag.

Type CodeMeaningExample

NNFC tagHPSN123456002
12 Registration & Billing

An asset ID is registered with the Beacon Telematics platform at the moment you download its QR or copy its NFC URL. This is a deliberate design choice — IDs generated in the tool but never downloaded are not registered and do not count towards usage.

Billable Action

Each unique asset ID registered counts towards your Beacon Telematics account usage. A confirmation dialog is shown before every download that registers one or more IDs. Re-downloading an already-registered ID does not create a duplicate charge.

13 FAQ

Does the person scanning need a Pinplot account?

No. The scan landing page is publicly accessible — anyone with a smartphone can scan an asset and update its location. This is intentional for use cases where field staff or drivers may not have platform credentials. Authentication can be added in a future release if required.

What happens if GPS is denied?

The landing page shows a clear message explaining that location access is required and how to re-enable it in the browser settings. No scan is recorded until a valid GPS position is available.

Can the same QR be scanned multiple times?

Yes. Every scan creates a new entry in the scan history. The asset's latest position on the map always reflects the most recent scan. There is no limit on the number of times an asset can be scanned.

What if the QR code gets damaged?

QR codes are generated with 25% error correction (Q level) by default, which means they can still be read when up to 25% of the code is obscured or damaged. For codes that carry a centre icon, error correction is automatically raised to 30% (H level).

What size should QR labels be printed?

A minimum of 25mm × 25mm is recommended for reliable scanning at arm's length. For outdoor use or scanning from distance (e.g. from a forklift), use 50mm × 50mm or larger. Always include the quiet zone (white border) that the generator adds automatically.

Can I use my own branding on the QR codes?

Yes. The generator supports custom foreground and background colours, corner colours, eight frame styles, and centre icon upload. The primary colour used throughout the platform can be changed in the tool's source to match your brand palette.
