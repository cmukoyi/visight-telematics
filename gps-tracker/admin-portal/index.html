⚙️ System Settings

Global configuration for trip engine and automatic processing

🔄 Trip Engine Configuration

Coalesce Floor controls how often the system fetches detailed track data from TrackSolid API for subscribed devices. Lower values = fresher trip data but more API calls. Higher values = less API usage but longer delays before trips appear.

Minimum time between automatic track data fetches for each subscribed device. This setting applies to all customer groups unless they have a custom override.

minutes

Recommended ranges:
• Real-time tracking: 30-60 minutes (higher API usage)
• Standard tracking: 60-120 minutes (balanced)
• Historical tracking: 120-240 minutes (lower API usage)

⚠️ Important: Changes to coalesce floor affect how quickly trips appear for subscribed devices. Lowering this value increases API calls to TrackSolid. Monitor API usage to avoid rate limits.
